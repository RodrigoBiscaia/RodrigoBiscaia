### <p align="center"><strong>✦ Projetos em Destaque ✦</strong></p>

### 📦 API de Controle de Estoque
API REST desenvolvida para gerenciamento de produtos e movimentações de estoque.

**Tecnologias:** Node.js, Express, SQLite, JWT e bcrypt.

- Autenticação e autorização de acesso via JWT.
- Cadastro, consulta, atualização e exclusão de produtos.
- Registro de entradas, saídas e ajustes de estoque.
- Pesquisa de produtos por nome e categoria.
- Organização do código em rotas, serviços e repositórios.
- Testes de endpoints e validação das funcionalidades.


### ☕ Microserviço de Usuários e Perfis
API REST para gerenciamento de usuários e permissões.

**Tecnologias:** Java, Spring Boot, Eureka e Maven.

- Operações CRUD para usuários.
- Gerenciamento de perfis e permissões.
- Regras de ativação e inativação de usuários.
- Integração com Service Discovery utilizando Eureka.

🔗 [Ver repositório](https://github.com/matheusBiscaia/microservico-usuarios-perfis)
